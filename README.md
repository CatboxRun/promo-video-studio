# 宣传视频快速生成器 · 本地测试版 0.1.0

将配音、字幕和素材整理成可复用的宣传片制作流程。包括分镜规划、素材来源核验、电视包装规范、数据动画规则、章节标题连续显示与交付检查。

当前可用：Codex工作流技能、项目初始化、环境检查、字幕时间检查、四种音轨组合的无损视频流重封装。
当前未包含：独立视频编辑器、全自动素材下载、转录服务、付费账户系统、云端渲染、实际订阅核验或自动扣款。

需要：支持插件的Codex、Python 3.10+，音视频导出需要自行安装FFmpeg。素材、字体、配音及AI使用额度由使用者提供。

安装包采用 `.codex-plugin/plugin.json` 布局，交给Codex的插件安装流程导入后，在新任务调用“宣传视频快速生成器”。安装兼容性以当前宿主实际验证为准；不能把解压视为已安装。

示例请求：“读取我的旁白和字幕，先做逐镜头脚本，再选素材，新闻画面统一电视包装，数字动态播放，导出4K字幕＋纯配音，无音乐、无音效。”
